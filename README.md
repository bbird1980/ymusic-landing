# ymusic-landing

Лендинг расширения «Яндекс.Музыка — управление плеером» для Chrome.
Статичная страница на чистом HTML/CSS, публикуется через GitHub Pages по
адресу [ymusic.bbird.ru](https://ymusic.bbird.ru).

Исходники самого расширения — в [ymusic-new](https://github.com/bbird1980/ymusic-new).

## Структура

- `index.html` — вся страница: разметка, адаптивные стили и JS карусели
- `assets/screenshots/` — скриншоты и промо-картинки из карточки Chrome Web Store
- `assets/icon-128.png` — иконка расширения
- `CNAME` — кастомный домен для GitHub Pages
- `news.json` — внеплановые объявления, которые опрашивает расширение
  (`shared/news.js` в репозитории расширения); формат, обязательность полей,
  типы и длины — в `news.md` рядом
- `news.md` — описание формата `news.json`

## Правка

Файл один, правки — прямо в `index.html`. Локально открывается просто
двойным кликом или `python3 -m http.server` в этой папке.

На экранах до 760 px скриншоты представлены портретными карточками с отдельными
текстовыми подписями. Область интерфейса задают `--crop-x`, `--crop-y`,
`--crop-w`, `--crop-h` и ширина исходника `--source-w`. По умолчанию используются
старые промо-изображения 1280×800. Обновлённые слайды используют подготовленные
изображения: `screenshot-1-player-enhanced.png` (1046×1504),
`screenshot-2-radio-enhanced.png` (963×1633),
`screenshot-4-ai-enhanced.png` (1031×1525) и
`screenshot-5-obs-enhanced.png` (1207×1303). У снимка OBS обрезаются узкие тёмные
поля, оставшиеся после обработки: область 1191×1292 с позиции (8, 4).
Скругление делает CSS.
Третий слайд использует исходный `screenshot-3-options-overview.png` (1960×1698)
без перерисовки: кадр 1960×1270 сохраняет шапку, меню и два полных блока настроек,
а незавершённый блок «Уведомления» снизу скрыт.
Шестой слайд использует исходный `screenshot-6-lastfm-updated.png` (1480×1032)
без перерисовки: внешние поля скрыты кадром 1406×974 с позиции (35, 27).
Это пробная обработка новых снимков встроенным imagegen: обрезка, увеличение
небольших исходников и повышение резкости. Генеративная обработка немного меняет
мелкие детали значков и текста. Прежние изображения сохранены для сравнения.
На телефоне автолистания нет, доступны свайпы,
стрелки и выбор слайда. Анимации учитывают `prefers-reduced-motion`.

На широком экране слева расположены заголовок и описание выбранной возможности,
справа — крупный фрагмент интерфейса. Кнопка установки находится в шапке. Шесть подписанных кнопок
снизу переключают скриншот, описание и цвет свечения. Подписи берутся из
`figcaption` соответствующего слайда. Автолистания нет на всех размерах экрана.
